# observer-repo
Chemical engineering coursework and projects — spatial heat mapping, separations, and process design work from my diploma, alongside self-taught Python.
Heat_map.py and interpolate.py aPython analysis for a lab experiment measuring temperature distribution 
across a tray, with and without a fan running. The code takes the 
recorded temperature readings, interpolates between measurement points, 
and generates color-coded graphs showing the heat distribution pattern 
across the tray for both conditions.

This code produced the analysis behind `Spatial_Heat_Mapping_Report.pdf`
